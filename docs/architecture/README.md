# Architecture Documentation

This folder contains architecture and planning material for the local-first AI music coach.

The project should remain documentation-first until the architecture is explicitly approved. Application source code should not be scaffolded before the requirements interview and architecture proposal are complete.

## Current documents

- [Requirements Interview](requirements-interview.md): known product direction, open architectural decision areas, and questions to answer before implementation.
