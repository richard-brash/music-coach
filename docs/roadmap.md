# Roadmap

This roadmap is a placeholder for an AI-powered offline music coach application. It focuses on product direction only and does not introduce application code.

## Phase 1: Discovery and foundations

- Define target users, instruments, practice scenarios, and accessibility needs.
- Identify the first set of coaching capabilities, such as rhythm accuracy, pitch stability, and practice streaks.
- Choose offline-first data and model constraints for supported devices.
- Prototype user flows for recording, reviewing, and receiving coaching feedback.

## Phase 2: Offline coaching prototype

- Build a local practice session experience with audio capture and playback.
- Add initial on-device music analysis for a narrow instrument or exercise type.
- Generate simple feedback summaries and recommended drills after each session.
- Validate privacy, latency, battery, and storage expectations.

## Phase 3: Personalized practice growth

- Add adaptive practice plans based on progress, goals, and recurring mistakes.
- Expand supported instruments, exercises, and coaching dimensions.
- Improve local model quality and explainability.
- Explore optional backup or sync features that do not compromise offline-first use.
